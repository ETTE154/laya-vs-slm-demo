Laya 제로샷 분류 모델과 SLM 1B · 3B가 동일한 과제를 순서대로 수행합니다.

LOCAL INFERENCE
실행 환경 확인 중…

01입력

동일한 입력을 세 모델에 전달Ctrl + Enter 실행

보기는 A. 답변, B. 답변처럼 한 줄에 하나씩 작성하세요.
Laya는 보기별 점수를 계산하고, SLM은 선택한 보기의 문자를 생성합니다. 생성 문자는 실시간으로 표시됩니다.

입력 예시
2+3?
A. 4
B. 5
C. 6
D. 7

로봇 제어 예시
Pick up the cube. The gripper is touching it, but it is not holding it yet. What should the robot do next?
A. Close the gripper to grasp the cube.
B. Lift the cube.
C. Release the cube.
D. Wait.
입력 후 실행하세요.

02결과

Laya → SLM 1B → SLM 3B
세 모델에 전달한 공통 과제

      
생성 속도 = (생성 토큰 수 − 1) / 첫 토큰부터 마지막 토큰까지의 시간. 첫 토큰 시간(TTFT)은 입력 처리와 prefill을 포함하며, 모델 로딩 시간은 별도입니다. 종료 토큰(EOS)도 토큰 수에 포함합니다. 보기 문자만 생성하므로 토큰 수가 적어 속도 편차가 큽니다.
Laya는 텍스트를 생성하지 않으므로 생성 토큰은 0이며, 생성 속도와 첫 토큰 시간은 표시하지 않습니다. 정답을 별도로 입력받지 않아 정확도는 자동으로 계산하지 않습니다. 실제 로봇 연결은 없습니다.
